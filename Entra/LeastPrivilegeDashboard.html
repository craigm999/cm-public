      Unmapped activities

      Activities by admins that aren't in LeastPrivilegeActivityMap.csv, so they couldn't be assessed. Add them to the map (Permissions = the resource actions needed, PreferredRoles = Microsoft's least-privileged role) and re-run the script.

      Entra audit logs don't record which role was used for an action. This report assumes the least-privileged active role that grants the permission was used, so "Over-privileged" means even that role was more than the task needed.

      "No role needed" covers self-service actions, user consent, and changes to objects the admin owns (based on current ownership). Some roles are limited by target (e.g. Helpdesk Administrator can only reset non-admin passwords), which isn't checked. Scoped (administrative unit) assignments are treated as tenant-wide.
