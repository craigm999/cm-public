      Users

      Data from Microsoft Graph user registration details (refreshed by Microsoft periodically, so very recent changes may not show yet). That report doesn't cover disabled accounts: they show as Unknown unless the script ran with -IncludeDisabledUserMethods.

      Phishing-resistant: FIDO2 keys, passkeys, Windows Hello for Business, macOS platform credential, certificate-based authentication. Phone methods (SMS / voice) are the weakest MFA. Email and security questions only count for self-service password reset.
