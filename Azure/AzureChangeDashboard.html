        Coverage of the report. Subscriptions with errors may be missing changes.

        Changes come from each subscription's Activity Log (kept for 90 days). "Create" is identified from the resource's creation time or Resource Graph; "Create or update" means the resource has since been deleted so it can't be told. Changed properties come from Azure Resource Graph and cover the last 14 days only.

        "via" shows the tool a person used (e.g. Azure CLI, Azure Portal). Changes made inside an ARM / Bicep deployment show the deployment name.
